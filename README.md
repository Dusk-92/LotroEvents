# 📅 LOTRO Events

Calendrier d’événements pour **The Lord of the Rings Online**, avec vue liste, vue calendrier et annonces optionnelles des événements actifs.

**🌍 Langues / Languages / Sprachen :** 🇫🇷 Français · 🇬🇧 English · 🇩🇪 Deutsch

---

## 🇫🇷 Français

### 📖 Présentation

**LOTRO Events** affiche les événements LOTRO actifs et à venir dans une interface dédiée, avec une vue **Liste** et une vue **Calendrier**.

### ✨ Fonctionnalités

- Événements actifs et prochains événements.
- Vue Liste et vue Calendrier.
- Dates ponctuelles et périodes d’événements.
- Gestion de l’heure serveur LOTRO.
- Conversion pour l’Europe et le Royaume-Uni avec changements d’heure.
- Annonces chat optionnelles pour les événements actifs.
- Icône et fenêtres configurables.
- Possibilité de masquer certains événements longs ou informations annexes.
- Interface FR / EN / DE.

### 📦 Installation

Copie le dossier **Dusk** dans :

```text
Documents\The Lord of the Rings Online\Plugins\
```

Puis en jeu :

```text
/plugins refresh
/plugins load LOTROEvents
```

### 🎮 Utilisation

Ouvre la fenêtre depuis l’icône ou une commande, puis bascule entre **Liste** et **Calendrier**. Les options permettent notamment de choisir le fuseau horaire et d’activer ou non les annonces dans le chat.

### ⌨️ Commandes

- `/events` — ouvrir/fermer LOTRO Events.
- `/lotroevents` — alias principal.

### ⚙️ Sauvegardes & réglages

Les préférences d’affichage, de fuseau horaire et d’annonces sont sauvegardées par le plugin.

### 🌍 Langues

L’interface est disponible en **français, anglais et allemand**.

### ⚠️ Limites / notes

Le calendrier est maintenu à partir du calendrier public officiel de Standing Stone Games. Les dates annoncées peuvent être modifiées par SSG ; les données du plugin doivent alors être mises à jour.

### 🐛 Bugs & suggestions

Utilise les [Issues GitHub](https://github.com/Dusk-92/LotroEvents/issues).

### 🙏 Crédits

Développement et maintenance : **Dusk-92**.  
Source des dates : calendrier public officiel **Standing Stone Games**.

**LOTRO Events** displays active and upcoming LOTRO events in a dedicated interface with both **List** and **Calendar** views.

- Active and upcoming events.
- List and Calendar views.
- One-day dates and multi-day event periods.

## 🇩🇪 Deutsch

### 📖 Übersicht

**LOTRO Events** zeigt aktive und kommende LOTRO-Ereignisse in einer eigenen Oberfläche mit **Listen-** und **Kalenderansicht**.

### ✨ Funktionen

- Aktive und kommende Ereignisse.
- Listen- und Kalenderansicht.
- Einzeltermine und mehrtägige Ereigniszeiträume.
- Unterstützung der LOTRO-Serverzeit.
- Zeitumrechnung für Europa und Großbritannien inklusive Zeitumstellung.
- Optionale Chat-Ankündigungen für aktive Ereignisse.
- Konfigurierbares Symbol und Fenster.
- Optionen zum Ausblenden ausgewählter langer Ereignisse oder Zusatzinformationen.
- Oberfläche auf FR / EN / DE.

### 📦 Installation

Den Ordner **Dusk** nach folgendem Pfad kopieren:

```text
Documents\The Lord of the Rings Online\Plugins\
```

Danach im Spiel:

```text
/plugins refresh
/plugins load LOTROEvents
```

### 🎮 Verwendung

Das Plugin über das Symbol oder einen Chatbefehl öffnen und zwischen **Liste** und **Kalender** wechseln. In den Optionen können unter anderem Zeitzone und Chat-Ankündigungen eingestellt werden.

### ⌨️ Befehle

- `/events` — LOTRO Events öffnen/schließen.
- `/lotroevents` — Hauptalias.

### ⚙️ Gespeicherte Daten & Einstellungen

Anzeige-, Zeitzonen- und Ankündigungseinstellungen werden gespeichert.

### 🌍 Sprachen

Die Oberfläche ist auf **Deutsch, Englisch und Französisch** verfügbar.

### ⚠️ Einschränkungen / Hinweise

Der Kalender basiert auf dem offiziellen öffentlichen Ereigniskalender von Standing Stone Games. SSG kann angekündigte Termine ändern; dann müssen auch die Plugin-Daten aktualisiert werden.
